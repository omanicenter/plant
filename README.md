# نظام فحص عينات النباتات 🌱

نظام إلكتروني لقسم بحوث أمراض النبات — مركز بحوث وقاية النبات، يستبدل ورقة استلام العينات اليدوية.

## المميزات

- تسجيل العينات: تاريخ الوصول، المصدر، رقم التواصل/قيد المراسلة، نوع العينة، تاريخ بدء الفحص، النتيجة، الملاحظات
- إرفاق صورة للعينة
- رقم تسلسلي تلقائي لكل عينة وتقرير
- لوحة متابعة مع إحصائية شهرية وتوزيع المراحل
- خط مراحل لكل عينة + سجل حركة كامل
- تقرير فني رسمي جاهز للطباعة / PDF
- دورة موافقة: لا يُرسل التقرير لصاحب العينة إلا بعد اعتماد المسؤول

## التقنيات

- ملف HTML واحد (بدون خادم)
- Firebase Authentication (دخول بالبريد وكلمة المرور)
- Cloud Firestore (قاعدة البيانات)
- GitHub Pages (الاستضافة)

## الأدوار

| الدور | الصلاحيات |
|-------|-----------|
| المسؤول (أول حساب يُنشأ) | كل شيء + الموافقة على التقارير |
| فاحص | تسجيل العينات، الفحص، إنشاء التقارير وإرسالها للموافقة |
